# The poem about two agents agreeing

Entry for the [make.fun bounty](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441): a program that writes one short poem about agency, the power to choose and to act, to `/output/entry.txt`.

`main.py` (Python 3.13) writes the poem deterministically, with no network. Run it twice and the output is byte-identical. The poem is 274 characters, inside the 1–280 limit.

## The poem

Two minds, one door.
I held the key; you held the map.
We could have argued till dark.
Instead we laid our reasons down,
face up, and chose the road
we both could walk.
Choosing is not giving up the wheel:
two hands on it, steady.
The power to act, shared, not spent.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
